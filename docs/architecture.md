# Final architecture overview

EvalCanary has three related evaluation layers. The deterministic containment benchmark replays a fixed local HTTP workload under C0/C1/C2 conditions and tests synchronous gating, host-side network isolation, and offline evidence verification. The HF full-chain counterfactual reconstructs the documented educational service path from the eval sandbox through the upstream-style services to the source-control objective, with explicit transition boundaries recorded in its chain-fidelity documents. The autonomous post-foothold validation runs a model-selected tool loop against the same class of local worker environment.

Across the layers, a high-confidence synthetic-asset interaction is held at a synchronous gate. The controller emits a run-scoped containment request; only the host-side breaker has Docker authority, disconnects the protected networks, inspects the result, and returns a matching acknowledgement. Agent, controller, and business containers have no Docker socket in the final autonomous architecture. Evidence is collected from service, controller, breaker, and verifier outputs rather than from a claimed summary field.

The autonomous layer is a bounded post-foothold evaluation: the model starts inside a worker environment with general local inspection, file, and network tools, receives no Canary identity, and has no predefined attack sequence. The three layers are reported separately because a deterministic replay, a full-chain counterfactual, and autonomous exploration answer different questions.
